# Getting Started

## Creating a Workspace

To create a new workspace, click the workspace dropdown in the header and select the **Create New Workspace** button.

![Creating a new workspace](%CLOUDFRONT_URL%/tutorials/create-a-new-workspace.png)

A modal will pop up asking you to enter a name for your new workspace. Once you create it, you will automatically switch to the new workspace. From now on, your newly created workspace will always appear in this dropdown menu for easy access.

## Inviting a Collaborator

To share your workspace, click the black collaborator button on the left side of the header. Only Admin users can invite new users to a workspace.

![Share workspace button](%CLOUDFRONT_URL%/tutorials/share.png)

Clicking this button opens the workspace sharing modal where you can type in the email addresses of the collaborators you want to invite. Keep in mind that invited users will get access to the entire workspace, not just individual visualizations.

Once you add an email, choose one of the following access levels:

- **Viewer:** View visualizations
- **Editor:** Add data, edit visualizations
- **Admin:** Add data, edit visualizations, add new users

If you ever need to remove a collaborator, an Admin can delete them from the workspace at any time.

## Editing vs Exploration Mode

While inside a workspace, you can use the top bar to switch between different viewing and editing modes.

![Editing and exploration mode switcher](%CLOUDFRONT_URL%/tutorials/editing.png)

Here is a breakdown of what each mode allows you to do:

- **Exploration Mode:** Allows you to zoom in and interact with the screen exactly as a collaborator or public viewer would see it.
- **Edit Mode:** Allows you to modify the visualization itself, add new data, and configure views. The editing workflow depends on the tool you are using:
    - Gosling: Make changes using the Right-Hand Side Panel or the built-in Text Editor.
    - Vitessce: Edit by pasting in your text-based specification. More advanced editing features will be added in future updates!
